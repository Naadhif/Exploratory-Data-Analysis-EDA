# Exploratory-Data-Analysis-EDA
Pembuatan Dataset Buatan (Synthetic Dataset): Kode menghasilkan data tiruan (dummy data) sebanyak 100 baris yang mencakup informasi mahasiswa seperti NIM, Jurusan, Kategori Kehadiran, Status Lulus, Jam Belajar per Minggu, Persentase Kehadiran, Skor Ujian Tengah, dan IPK, lalu menyimpannya ke dalam file CSV.
